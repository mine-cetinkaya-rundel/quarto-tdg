# Syntax in this book that changes in Quarto 2

Quarto 2 is in development. The examples in this book use syntax that works
in Quarto 1 and Quarto 2 where possible. This file lists the cases where
that is not possible. For each case, it shows the Quarto 1 syntax that the
book uses and the Quarto 2 syntax to use instead.

## Footnotes with more than one paragraph

The book uses the Quarto 1 syntax. Each extra paragraph has an indent of
four spaces:

```markdown
Here is some text that needs a long footnote.[^longnote]

[^longnote]: Here's the footnote contents with multiple blocks.

    Subsequent paragraphs are indented to show that they
    belong to the previous footnote.
```

In Quarto 2, put the footnote contents in a fenced div. The label of the
div is the footnote label:

```markdown
Here is some text that needs a long footnote.[^longnote]

::: ^longnote
Here's the footnote contents with multiple blocks.

Subsequent paragraphs are not indented. The div holds them.
:::
```

Quarto 2 does not accept the indented paragraph. Quarto 1 does not
recognize the fenced div as a footnote.

A footnote with one paragraph uses the same syntax in both versions.

## Math macros

The book uses the Quarto 1 syntax. Each `\newcommand` is on its own line in
the body of the document, outside any `$` or `$$`. The macros then apply to
all the math in the document:

```markdown
\newcommand{\R}{\mathbb{R}}
\newcommand{\vect}[1]{\mathbf{#1}}
\newcommand{\Var}{\operatorname{Var}}

For any $\vect{x} \in \R^n$,

$$
\Var(\vect{x}) \geq 0.
$$
```

Quarto 2 does not accept a `\newcommand` outside math. In Quarto 2, a
`\newcommand` applies only to the math expression that contains it. Put
each definition in each expression that uses the macro:

```markdown
For any $\newcommand{\R}{\mathbb{R}}\newcommand{\vect}[1]{\mathbf{#1}}\vect{x} \in \R^n$,

$$
\newcommand{\vect}[1]{\mathbf{#1}}
\newcommand{\Var}{\operatorname{Var}}
\Var(\vect{x}) \geq 0.
$$
```

The Quarto 2 syntax also works in Quarto 1, but it repeats each definition.
The book also shows how to share macros between documents with an include
file, for example `_macros.qmd`. In Quarto 2, this does not work, because
the include file has `\newcommand` lines outside math.
